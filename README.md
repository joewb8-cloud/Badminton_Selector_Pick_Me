# Badminton Player Selector

A free, offline-capable web app for picking fair badminton doubles games.

**Features:** 1 or 2 courts · rotates partners so everyone plays with everyone · fair court time ·
skill-balanced teams (Elo ratings from results) · Manual Pick for choosing who goes on court ·
Export/Import of players and history · works offline and installs like an app.

## Use it
Open the GitHub Pages link, then:
- **Android (Chrome):** menu ⋮ → *Add to Home screen* / *Install app*
- **iPhone (Safari):** Share → *Add to Home Screen*
- **PC (Chrome/Edge):** click the install icon in the address bar

Data is saved on your own device (browser storage). Use **Export** to back it up or move it to another device.

## Host it yourself
1. Upload all files to a GitHub repository (keep the `icons` folder).
2. Repository **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
3. After a minute your app is live at `https://<username>.github.io/<repo-name>/`.
